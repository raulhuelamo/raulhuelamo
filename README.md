### How I work

I don't write the code anymore: AI agents do. I design the system they work in, and how much system depends on what's at stake:

- **Exploring** — a prototype, an idea worth a weekend: fast loops, little ceremony, thrown away if it doesn't land.
- **Building to last** — something people rely on: a knowledge notebook the agents read before touching anything, quality gates on every commit, guardrails that won't let a broken change through.

Either way, I stay in the loop for every decision that matters. [How I work today →](HOW-I-WORK.md)
